# Fight Tracking — Next Level 🥋

Interactive Taekwondo athlete dashboard:
- Editable profile, belt, goals, accent and theme
- Add/delete training sessions and schedules
- Add/delete matches
- Add/edit/delete kick techniques
- Belt roadmap
- XP + level
- Ranking
- Custom achievements
- LocalStorage persistence
- Bundled user-provided music in `assets/song.mp3`
- Responsive desktop/mobile

Deploy directly to GitHub Pages.
