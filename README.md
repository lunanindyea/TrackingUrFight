# Fight Tracking — Custom Edition 🥋

Aplikasi tracker Taekwondo yang interaktif dan bisa dicustom.

## Bisa dipencet & diubah
- Tambah/hapus sesi latihan
- Tambah/hapus pertandingan
- Tambah/edit/hapus teknik tendangan
- Unlock/lock achievement
- Tambah achievement sendiri
- Edit nama, inisial, dan sabuk atlet
- Ganti accent color dan mode tampilan
- Atur target latihan & repetisi tendangan
- Data tersimpan otomatis di browser (localStorage)
- Lagu `assets/song.mp3` dari pengguna tersedia melalui tombol musik
- Fallback memilih lagu sendiri dari perangkat
- Responsive desktop/mobile

## GitHub Pages
Upload seluruh isi folder ini ke repository GitHub, lalu aktifkan Settings → Pages → Deploy from branch → main → /(root).
